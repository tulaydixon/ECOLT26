3. Creating objects with the assignment operator <-

An important feature of R is to create objects.

Objects are used to store a variety of values: numbers, lists, entire datasets, and more. Storing these values as objects allows us to use them again and again, without retyping them.

We create objects using the assignment operator: <- , which is a less than sign, <, followed by a minus sign, -.

4. Using Functions & Arguments

Functions are small programs inside R that perform tasks for us. R comes with many built-in functions like summary(), mean(), and plot().

Arguments are the inputs you provide to a function to customize its behavior or to provide the data on which it operates.

Many functions of R live in packages. Packages are similar to apps on your phone. Your phone is powerful as is, but you can make it more powerful and add new features to it by installing new apps. Similarly, R is strong as is, but we can add new functions to it by installing new packages.
